# Security Policy

Report vulnerabilities privately by email to the maintainer (add your address here) or via
GitHub's "Report a vulnerability" button. Please do not open public issues for security bugs.

## Trust model
Deposits and refunds are enforced by the `TumaEscrow` contract. The claim step is trusted:
the server operator wallet decides the release recipient after verifying the X login.
See the README "Trust model" section.
